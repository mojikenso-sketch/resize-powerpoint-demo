Resize PowerPoint — เวอร์ชันทดลอง (DEMO) สำหรับ GitHub Pages
==============================================================

1) นี่คืออะไร
   - โปรแกรมย่อไฟล์ PowerPoint (.pptx) ที่ทำงานในเบราว์เซอร์ 100%
     ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ เลือกได้ 5 ระดับความชัด และเห็นขนาดไฟล์ก่อนดาวน์โหลด
   - โฟลเดอร์ docs/ คือเว็บแบบ static พร้อมเผยแพร่บน GitHub Pages
     (ฟอนต์และไลบรารี JSZip อยู่ในโฟลเดอร์เอง ไม่ต้องพึ่ง CDN)
   - ตัดไฟล์ usage.php / .htaccess ออก (GitHub Pages รัน PHP ไม่ได้)
     สถิติ "เปิดเว็บ / ดาวน์โหลด" ที่ท้ายหน้า จึงนับเฉพาะในเบราว์เซอร์นั้นๆ (localStorage)

2) ระบบทดลองใช้ฟรี 3 วัน ทำงานอย่างไร
   - เปิดเว็บครั้งแรก ระบบจะจดเวลาเริ่มทดลองไว้ใน localStorage ของเบราว์เซอร์
     (คีย์ demo_rpp_trial_start)
   - ด้านบนของหน้าจะมีแถบแจ้ง "เวอร์ชันทดลองใช้ฟรี 3 วัน · เหลืออีก X วัน Y ชม." พร้อมข้อความติดต่อ
   - ระหว่างทดลองใช้ได้ครบทุกฟังก์ชัน ไม่จำกัดอย่างอื่น
   - ครบ 3 วันแล้ว เมื่อเลือกไฟล์เพื่อบีบอัดหรือกดดาวน์โหลด จะขึ้นหน้าต่าง
     "หมดระยะทดลองใช้ 3 วันแล้ว" พร้อมราคาและช่องทางติดต่อ
   - การนับเป็นแบบ "ต่อเบราว์เซอร์": เปลี่ยนเบราว์เซอร์/เครื่อง หรือล้างข้อมูลเว็บไซต์ (Clear site data)
     จะเริ่มนับ 3 วันใหม่ — ยอมรับได้สำหรับเวอร์ชันสาธิต
   - ถ้าเบราว์เซอร์ปิดการใช้ localStorage (เช่นบางโหมดส่วนตัว) ระบบจะให้ใช้งานได้ตามปกติ

3) วิธีเผยแพร่บน GitHub Pages
   1. สร้าง repository ใหม่บน GitHub (เช่น ResizePowerPoint) แบบ Public
   2. ในโฟลเดอร์นี้ (มี git init และ commit ไว้แล้ว) สั่ง
        git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อrepo>.git
        git push -u origin main
   3. ไปที่ repository บน GitHub → Settings → Pages
      Source: Deploy from a branch → Branch: main → Folder: /docs → Save
   4. รอ 1-2 นาที เว็บจะอยู่ที่ https://<ชื่อผู้ใช้>.github.io/<ชื่อrepo>/

4) แก้ข้อความติดต่อ / ราคา
   - เปิดไฟล์ docs/config.js แล้วแก้ค่า
        window.DEMO_CONTACT = 'สนใจซื้อสิทธิ์ใช้งาน ติดต่อ: Fastwork / LINE: (ใส่ภายหลัง)';
        window.DEMO_PRICE   = 'สิทธิ์ใช้งานรายปี 990 บาท/ผู้ใช้/ปี · ขายขาด 1,990 บาท/ผู้ใช้';
        window.DEMO_TRIAL_DAYS = 3;
   - แนะนำให้เปลี่ยน ?v=1 ใน docs/index.html (บรรทัด config.js) เป็น ?v=2 ทุกครั้งที่แก้
     เพื่อให้เบราว์เซอร์โหลดค่าใหม่ แล้ว commit + push ตามปกติ
