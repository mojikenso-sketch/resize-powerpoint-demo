Resize PowerPoint — เวอร์ชันทดลอง (DEMO) สำหรับ GitHub Pages
==============================================================

1) นี่คืออะไร
   - โปรแกรมย่อไฟล์ PowerPoint (.pptx) ที่ทำงานในเบราว์เซอร์ 100%
     ไม่มีการอัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ มี 5 ระดับความชัด และเห็นขนาดไฟล์ก่อนดาวน์โหลด
   - โฟลเดอร์ docs/ คือเว็บแบบ static พร้อมเผยแพร่บน GitHub Pages
     (ฟอนต์และไลบรารี JSZip อยู่ในโฟลเดอร์เอง ไม่ต้องพึ่ง CDN)
   - ตัดไฟล์ usage.php / .htaccess ออก (GitHub Pages รัน PHP ไม่ได้)
     สถิติ "เปิดเว็บ / ดาวน์โหลด" ที่ท้ายหน้า จึงนับเฉพาะในเบราว์เซอร์นั้นๆ (localStorage)
   - เวอร์ชันทดลองนี้ "ให้ลองพอเห็นภาพ": ใช้ได้ 2 จาก 5 ระดับ และไฟล์ไม่เกิน 30 MB (ดูข้อ 2)

2) ระบบทดลองใช้ฟรี 5 ชั่วโมง (1 ครั้งต่อคน นับตาม IP + อุปกรณ์)
   - ใช้ระบบ Trial Gate ตัวเดียวกับเดโมอื่นๆ (ไฟล์ docs/js/trial-gate.js — คัดลอกมาจาก
     DEMO/TrialGate/client/trial-gate.js ห้ามแก้ไข) ร่วมกับ Web App "Trial Gate" (Google Apps Script)
   - ** ต้องตั้งค่า DEMO_TRIAL.gateUrl ใน docs/config.js ** ให้เป็น URL ของ Web App Trial Gate
     (ลงท้ายด้วย /exec) ถ้ายังเป็น 'PASTE_TRIAL_GATE_URL_HERE' ระบบจะไม่จำกัดเวลาเลย
   - เปิดเว็บครั้งแรก เบราว์เซอร์จะส่ง IP สาธารณะ + รหัสอุปกรณ์ (สุ่มเก็บใน localStorage) ไปที่ Trial Gate
     เซิร์ฟเวอร์เป็นผู้ตัดสินเวลาที่เหลือ (app = 'resize-ppt') — เปลี่ยนเบราว์เซอร์แต่ IP เดิม ก็ยังนับต่อ
   - มุมซ้ายล่างจะมีป้าย "⏳ เวลาทดลองของคุณเหลือ ..." และแถบด้านบน
     "🧪 เวอร์ชันทดลองใช้ฟรี 5 ชั่วโมง (1 ครั้งต่อคน)" พร้อมข้อความติดต่อ
   - ครบ 5 ชั่วโมง จะขึ้นหน้าจอเต็ม "หมดเวลาทดลองใช้ 5 ชั่วโมงแล้ว" พร้อมราคาและช่องทางติดต่อ
     และการเลือกไฟล์ / ดาวน์โหลด จะไม่ทำงาน
   - ถ้าติดต่อ Trial Gate ไม่ได้ (เน็ตล่ม / เซิร์ฟเวอร์ไม่ตอบ) เดโมยังใช้งานได้ตามปกติ (fail-open)
   - ไฟล์ PowerPoint ของลูกค้า ไม่ถูกส่งออกจากเครื่อง (ส่งเฉพาะ IP + รหัสอุปกรณ์ เพื่อนับสิทธิ์)

   สิ่งที่ล็อกไว้ในเวอร์ชันทดลอง (ตั้งค่าใน docs/js/trial.js)
   - ระดับความชัด: ใช้ได้ 2 ระดับ คือ "สมดุล" (แนะนำ) และ "เล็กที่สุด"
     อีก 3 ระดับ ("ประหยัดพื้นที่", "คมชัด", "คมชัดสูง") ยังแสดงให้เห็นพร้อมขนาดไฟล์ที่คาดว่าจะได้
     แต่ติดป้าย 🔒 เวอร์ชันเต็ม กดแล้วจะขึ้นกล่องแจ้ง "🔒 ระดับนี้มีในเวอร์ชันเต็ม — (ข้อความติดต่อ)"
     (แก้รายการได้ที่ ALLOWED_KEYS)
   - ขนาดไฟล์: รับไฟล์ไม่เกิน 30 MB ต่อไฟล์ (เวอร์ชันเต็มไม่จำกัด) — แก้ได้ที่ MAX_FILE_MB

3) วิธีเผยแพร่บน GitHub Pages
   1. สร้าง repository ใหม่บน GitHub (เช่น ResizePowerPoint) แบบ Public
   2. ในโฟลเดอร์นี้ (มี git init และ commit ไว้แล้ว) สั่ง
        git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อrepo>.git
        git push -u origin main
   3. ไปที่ repository บน GitHub → Settings → Pages
      Source: Deploy from a branch → Branch: main → Folder: /docs → Save
   4. รอ 1-2 นาที เว็บจะอยู่ที่ https://<ชื่อผู้ใช้>.github.io/<ชื่อrepo>/

4) แก้ข้อความติดต่อ / ราคา
   - เปิดไฟล์ docs/config.js แล้วแก้ค่า
        window.DEMO_CONTACT = 'สนใจซื้อสิทธิ์ใช้งาน ติดต่อ: Fastwork / LINE: (ใส่ภายหลัง)';
        window.DEMO_PRICE   = 'สิทธิ์ใช้งานรายปี 990 บาท/ผู้ใช้/ปี · ขายขาด 1,990 บาท/ผู้ใช้';
        window.DEMO_TRIAL = {
          gateUrl: 'PASTE_TRIAL_GATE_URL_HERE',   // <- ใส่ URL Web App Trial Gate (/exec)
          app: 'resize-ppt', hours: 5,
          contact: window.DEMO_CONTACT,
          priceHtml: 'สิทธิ์ใช้งานรายปี 990 บาท/ผู้ใช้/ปี · ขายขาด 1,990 บาท/ผู้ใช้' };
     - hours ใช้แสดงผลเท่านั้น เวลาจริงกำหนดที่ฝั่ง Trial Gate
   - แนะนำให้เปลี่ยน ?v=2 ใน docs/index.html (บรรทัด config.js) เป็น ?v=3 ทุกครั้งที่แก้
     เพื่อให้เบราว์เซอร์โหลดค่าใหม่ แล้ว commit + push ตามปกติ
